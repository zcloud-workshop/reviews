Reviews 文档题库模板

使用说明：
1. 每道题以数字编号开头，例如：1.、2、或 3）。
2. 选择题的每个选项独占一行，格式为 A. 内容、B. 内容、C. 内容。
3. 答案独占一行，格式为“答案：B”。
4. 多选题在题目中写“选择两项”或“选择多项”，答案写成“答案：AC”。
5. 判断题建议在题目开头写“判断题：”，答案写“正确”或“错误”。
6. 填空题用连续 6 个以上下划线表示空格，多个答案用逗号分隔。
7. 简答题直接写题目和参考答案。
8. 可用“# 模块1”或“第1章”作为章节标题；章节标题不会被识别为题目。

以下内容可以直接复制到 Word，保存为 .docx 或 .doc 后导入：

# 模块1：示例题库

1. 以下哪项是 HTTP 默认端口？（选择最佳答案。）
A. 21
B. 53
C. 80
D. 443
答案：C

2. 以下哪些属于应用层协议？（选择两项。）
A. HTTP
B. TCP
C. DNS
D. IP
答案：AC

3. 判断题：HTTPS 在 HTTP 的基础上增加了 TLS 加密。
答案：正确

4. IPv4 地址由 ______ 位二进制数组成。
答案：32

5. 简述 DNS 的作用是什么？
答案：DNS 用于把域名解析为 IP 地址。
