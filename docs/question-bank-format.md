# JSON 题库格式

使用 `question-bank-template.json` 作为新题库的起点。首页“导入题库”只接受 UTF-8 编码的 `.json` 文件，根对象固定如下：

```json
{
  "formatVersion": 1,
  "modules": []
}
```

每个模块包含非空的 `id`、`name`、可选 `description` 和至少一个 `days` 练习组。每个练习组包含非空的 `id`、`title` 和至少一个 `questions` 题目。模块 ID、模块名称、练习组 ID 和题目 ID 必须在同一导入文件内保持唯一。

题型和 `answer`：

| `type` | `options` | `answer` |
| --- | --- | --- |
| `choice` | 至少两个字符串 | 正确选项下标，从 `0` 开始 |
| `multi` | 至少两个字符串 | 不重复的正确选项下标数组 |
| `judge` | 可省略 | `true` 或 `false` |
| `fill` | 可省略 | 至少一个标准答案组成的字符串数组 |
| `shortAnswer` | 可省略 | 参考答案字符串；用户提交后自行核对 |

导入前应用会校验所有字段、题型和答案下标。若发现错误，会显示模块、练习组和题号位置；错误文件不会写入本地数据。与现有模块同名或同 ID 时，可选择“覆盖导入”（只覆盖此前导入的模块）或“另存导入”。内置示例模块不会被覆盖。
